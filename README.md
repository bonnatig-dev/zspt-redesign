# ЗСПТ — концепт редизайна главной (Local Media)
Статическая главная (HTML/CSS/JS) с мобильной адаптацией. Тексты, логотип, контакты и фото взяты с zspt.by (фото переведены в WebP). Стоковые фото не используются.
Уточнить у клиента: срок работы компании («5 лет» vs «2012–2023»), фото/описание кавитационных теплогенераторов, названия партнёров для логотипов, текст политики ПД.
Форма — демо: валидация и сообщение-заглушка, без отправки. Карты — виджеты Яндекс.Карт (Минск, Липковская 22/2; Орша, Шкловская 2-я, 22А).
